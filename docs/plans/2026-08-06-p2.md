## 飞牛 FPK（Native）

已从 Docker Compose 改为 [Native 应用](https://developer.fnnas.com/docs/examples/native/)：

- `install_dep_apps=nodejs_v22`
- 网关前缀 `/app/miyin`，Socket `app.sock`
- `cmd/main` start/stop/status
- `data-share`：`miyin/data`、`miyin/downloads`
- 构建：`pnpm build:fpk` 或 `./packaging/fnos/scripts/build-fpk.sh`

注意：请在与 NAS 相同 CPU 架构上构建，以便 `better-sqlite3` 原生模块可用。

## 歌单匹配确认

1. 解析歌单并多选曲目  
2. 「下载选中」先调用 `/api/playlist/match`  
3. 分值 &lt; 0.7 或未命中 → 前端确认候选项 / 跳过  
4. 确认后带 `musicInfo` 入队
