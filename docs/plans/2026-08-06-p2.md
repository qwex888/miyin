## 实现清单

### 1. 歌单

- `POST /api/playlist/parse` — 解析网易云 playlist 链接
- `POST /api/playlist/enqueue` — 解析 + TrackMatcher 匹配 + 批量入队（`batchId`）
- 页面：`/playlist`，粘贴链接一键入队
- 匹配策略：ID 优先 + 元数据回退（复用 `trackMatcher`）

### 2. SSE

- `GET /api/downloads/events` — `text/event-stream`
- 事件：`snapshot`（全量）、`task`（单条更新）
- 队列页优先用 EventSource，失败则回退 2s 轮询

### 3. FPK 骨架

```
packaging/fnos/miyin/
  manifest
  app/docker/docker-compose.yaml
  README.md
```

二期补齐：图标、cmd 生命周期脚本、真实镜像名与商店提交。
